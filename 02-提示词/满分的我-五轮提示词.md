# 《满分的我》提示词（Prompts）· 共 6 轮

> 文档编号 **DOC-B2** ｜ 阶段：视觉 · 提示词 ｜ 版本 v1.0 ｜ 更新 2026-10-10
> 关联：`03-角色设定/人物设定.md`、`04-分镜图/` ｜ 索引：`00-文档总览.md`

> 用途：本工程所有原创角色图、场景图、分镜图均由本地 **Qwen-Image-2.1** 依据下列提示词生成。
> 同一套提示词迁移到 Midjourney / SD / 即梦 / 可灵等工具时，只需替换风格后缀。
> 结构：**第1轮＝开头** → **第2—5轮＝中间** → **第6轮＝最后**（共 6 轮，满足"≥5 轮"要求）。
> 一致性约定：角色统一定义为 `林一/A B≈15岁男高中生，黑色短碎发，深蓝水手领校服`，跨轮复用。

---

## 风格定位：轻薄半赛璐 / 淡彩赛璐（Soft Cel + Paper Texture）

**全片统一画风**（校园题材适配度最高）：

- **弱化黑轮廓线，改用彩色线稿**（深蓝灰 / 暖褐描线）；
- 赛璐大块平涂阴影基础上，**叠加极淡水彩晕染 + 纸张颗粒纹理**；
- 体积光更朦胧，**不做强烈光束**，偏向漫射空气光；
- 阴影内部带**微弱环境色晕染**，无厚涂笔触，手绘 analog 温度；
- 观感像水彩绘本动画，温柔、文艺、故事感强。

> 统一风格前缀（下列各轮提示词均已内嵌，跨工具迁移可复用）：
>
> ```
> 轻薄半赛璐淡彩动漫风格：弱化黑色轮廓线、改用深蓝灰与暖褐彩色线稿，
> 赛璐平涂阴影上叠加极淡的水彩晕染与纸张颗粒纹理，柔和漫射空气光，
> 朦胧体积光不做强光束，阴影内带微弱环境色晕染，无厚涂笔触，水彩绘本质感
> ```

## 第 1 轮（开头）· 片头背景 + 主角锚定

**目的**：锁定全片画风、色彩基准，生成**片名字幕背景图**与主角"林一"的原创形象。

```

改用深蓝灰与暖褐彩色线稿，赛璐平涂阴影叠加极淡水彩晕染与纸张颗粒纹理，
柔和漫射空气光，朦胧体积光不做强光束，无厚涂笔触，水彩绘本质感。
画面：空无一人的午后高中教室，木质课桌整齐排列，大窗透入柔和散射天光，
冷灰蓝与一抹微暖余晖交织，中央偏上留出大片低对比度留白用于叠加片名。
16:9，无人物，无文字，无水印。
```

**提示词 B（主角主形象）：**

```
[风格前缀] 主角：一名15岁中国男高中生"林一"，身高172cm偏瘦，黑色短碎发、

## 第 3 轮（中间②）· 三名角色一致性表 + 虚拟自我"一林"

**目的**：固定三名角色与关键对照符号（校徽空白凹槽 vs 发光满环）。

**提示词：**

```
[风格前缀] 原创角色三视图设定表，白色背景，同一画风：
①林一（现实自我）：15岁男高中生，黑色短碎发，深蓝水手领校服，左胸校徽为
  空白凹槽，眼神疲惫但勉强微笑；
②一林（理想/应该自我）：与林一同脸同身高，头发一丝不乱，皮肤通透，眼中
  高光，同款校服笔挺反光，全身带青蓝色柔光描边，左胸校徽是一枚发光的
  圆环（象征满分），标准微笑直视镜头；
③陈晓（朋友）：15岁女高中生，齐肩黑发扎低马尾，脸型偏圆，浓眉，挽起袖子，
  橙色发圈，运动鞋，表情平静。
三人并排，比例一致，标注留白，16:9，无文字，无水印。
```

**产出**：`04-分镜图/角色/三人设定表.png`

**提示词（可拆多条）：**

```

   背景虚化的洗手间瓷砖，紧张感，无真实APP图标，16:9。
B. 教室中景，林一坐着打开手机，屏幕亮起；一个由像素光点聚成、全身青蓝柔光的

   左右明暗对照，16:9，无文字。
C. 左右分屏：左侧冷色现实中疲惫的林一，右侧明亮完美的一林，中缝是一道屏幕光带，
   情绪压抑，16:9，无文字。

## 第 5 轮（中间④）· 心理学高潮：三面镜子 + 暖色反转

**目的**：把抽象的"自我差异理论"转成直观视觉，并完成由冷转暖的情绪回收。

**提示词（可拆多条）：**

```
A. 男孩伸手触碰透明镜面，镜面泛起涟漪，镜上浮现三行手写笔迹（画面不显示可辨文字，
   仅示意）："现实的我"（冷灰蓝）、"理想中的我"（青蓝发光）、
   "我以为自己必须成为的我"（过曝高亮、带裂纹），16:9。
B. 理论示意构图：现实中的男孩站在阴影里，理想中的完美自我站在光里，中间是一道
   落差光带，象征性强，无文字，16:9。
C. 镜面温柔碎裂，碎片化作柔和暖色光点落在男孩身上，色温由冷蓝转向暖橙，治愈感。
D. 黄昏操场远景，两个高中生逆光奔跑，暖橙色夕阳，剪影感，开朗释放，16:9。
```

**产出**：`04-分镜图/镜头/S14-镜面包围.png`、`S15-捂耳朵.png`、`S17-触碰镜面.png`、`S19-理论示意.png`、`S22-暖色光点.png`、`S29-黄昏奔跑.png`

## 第 6 轮（最后）· 情绪落点与片尾校验

**目的**：生成"不再摆拍的真实笑容"与片尾定格，并校验全片基调积极、原创。

**提示词：**

```
A. 傍晚教室，陈晓向林一伸出手，林一自然、放松地笑了，没有看镜头、没有拿手机，
   暖色夕阳从窗户洒入，温暖，16:9，无文字。
B. 卧室特写，台灯暖光下，林一看了一眼亮起的手机（新点赞提示），主动把手机屏幕
   朝下放下，继续整理明天要用的课本，平静安心，16:9，无文字。
C. 片尾定格：林一真实自然的笑容，柔和暖光，浅景深，留白用于叠加一句字幕的空间。
```

**片尾电影滚动字幕**（由 `build/build.py` 的 `credits_clip()` 生成，黑底向上滚动）：

- **片名与副标题**；
- **本片揭示的心理学理念**：自我差异理论（Self-Discrepancy Theory，E. Tory Higgins，1987）及现实自我 / 理想自我 / 应该自我；
- **制作工具与组件**：Qwen-Image-2.1、Krita、OpenToonz、Kdenlive / MLT、FFmpeg、ASS、原创环境配乐、思源宋体 / 微软雅黑，并标注"本地 AI 智能体协助制作 · 全流程原创"；
- **致谢与给所有人的最好祝福**；
- **版权页**：原创声明与署名。

**校验清单（生成后人工核对）：**
- [x] 无任何网络/第三方素材或品牌标识
- [x] 角色在各幕中发型、校服、符号（凹槽 / 发光满环）保持一致
- [x] 色彩曲线：冷蓝（1—3幕）→ 暖橙（4—5幕）
- [x] 画风统一为「轻薄半赛璐 / 淡彩赛璐（Soft Cel + Paper Texture）」
- [x] 主题积极：不否定努力，只否定"必须先完美才配被喜欢"
- [x] 含完整情节、明确主题、细节合理

**产出**：`04-分镜图/镜头/S26-陈晓伸手.png`、`S27-真实的笑.png`、`S31-放下手机.png`、`S32-片尾定格.png`
