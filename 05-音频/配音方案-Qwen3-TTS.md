# 《满分的我》配音方案 · Qwen3-TTS

> 文档编号 **DOC-C2** ｜ 阶段：音频 · 配音与混音 ｜ 版本 v1.0 ｜ 更新 2026-10-10
> 关联：`05-音频/音频与音乐说明.md`、`build/tts_dub.py`、`build/mix_dub.py` ｜ 索引：`00-文档总览.md`

> 通过本机 GPUStack 部署的 **Qwen3-TTS-12Hz-1.7B-VoiceDesign** 生成配音。
> 该模型支持"用自然语言描述音色"，可为三个角色设计互不相同的原创声音。

## 一、部署信息

| 项目 | 值 |
|---|---|

## 二、角色音色设计（VoiceDesign 提示词）

三个角色为**互不相同的原创少年音**，旁白用**播音员旁白**。

| 角色 | `instructions`（音色指令） | 定位 |
|---|---|---|
| **林一** | 17岁中国高中男生，清亮的中音，声音自然，略带疲惫，敏感克制，情绪细腻，普通话标准，语速稍慢，像在压抑地自述 | 自然、略带疲惫 |
| **一林** | 17岁中国高中男生，音色清晰、稳定、冷静，吐字利落，语气笃定，带一点距离感，干净的少年播音腔，不要机械电子音 | 清晰、冷静、略有距离感 |
| **陈晓** | 17岁中国高中女生，音色温暖明亮、中性偏暖，语气自然随和，轻松生活化，像真实同学在聊天，亲切不煽情，吐字清晰 | 温暖、轻松、生活化 |
| **旁白** | 成熟稳重的男声播音员旁白，字正腔圆，语速平稳，温和有磁性，叙述克制、无评判 | 播音员旁白 |
| **镜面声** | 一林叠声，压低音量、气声低语，克制中带压迫感，像许多个自己在耳边重复 | 一林音色叠声（V11） |

> 设计原则：林一与一林"同源不同调"，隐喻"两个自我"；陈晓是全片唯一的暖色女声；旁白与三个角色区分，作客观叙述。
>
> 陈晓与 `03-角色设定/人物设定.md` 一致，为**女生**（温暖明亮的少女音）。

## 四、多轨混音与成片

成片音轨按以下轨道组织（`build/mix_dub.py` 生成，脚本：`python3 build/mix_dub.py`）：

| 轨道 | 内容 | 来源 |
|---|---|---|
| **V1** | 动画画面（含既有氛围叠加与字幕） | `07-成片/高一1班-朱明萱-满分的我.mp4` 视频流 |
| **A1** | 林一 对白 | Qwen3-TTS 逐句 → `05-音频/多轨/A1_林一.wav` |
| **A2** | 一林 对白（含 V11 镜面叠声） | `A2_一林.wav` |
| **A3** | 陈晓 对白 | `A3_陈晓.wav` |
| **A6** | 旁白（播音员） | `A6_旁白.wav` |
| **A4** | 配乐：焦虑 → 冲突 → 释然 | ACE-Step 三段交叉淡化 `A4_配乐.wav` |
| **A5** | 音效：手机提示音 / 镜面音效 / 操场环境声 | 合成占位 `A5_音效.wav` |

- 混音（`build/mix_dub.py`）：对白 4 轨合并后 **高通 90Hz + 3kHz 提升 + 整体抬升**，
  再经 `sidechaincompress`（thr 0.05 / ratio 20）在对白出现时**强力闪避配乐**，
  音效轨高通后突出叠加；最后用**两遍 `loudnorm(linear)`** 静态归一至 **−16 LUFS / TP −1.5dBTP**
  （不用单遍动态归一，避免抽吸、保住对白—配乐对比）。实测对白区比纯配乐区高约 **7dB**。
- **时间轴对齐**：镜头/台词/音效统一声明在 `build/scene.py`；`build.py` 生成 `build/timeline.json`
  （镜号 → 成片起点秒），`tts_dub.py` / `mix_dub.py` 据此把「镜号 + 镜内偏移」解析为绝对秒，无需手工换算。
- 输出整轨 `build/mix.wav`；成片
  `07-成片/高一1班-朱明萱-满分的我(配音版).mp4`（V1 直拷 + AAC 192k 新音轨，约 2:32）。
- A5 音效由 `build/sfx_gen.py` **程序化合成**（纯 Python，无第三方素材），覆盖手机提示音、
  心跳、纸页、快门、笔尖/秒针、像素上浮、玻璃嗡鸣/回声、声音抽空、水滴、笔迹浮现、操场环境声等；
  时间点见 `build/scene.py` 的 `SFX`。

## 五、生成与复现

台词以成片字幕 `07-成片/满分的我-字幕.srt` 的时间轴为准，由 `build/tts_dub.py` 生成：

```bash
python3 build/tts_dub.py            # 生成全部台词 + 合成整轨 build/voice.wav
python3 build/tts_dub.py audition   # 只生成 4 条音色试听
python3 build/sfx_gen.py            # 生成 A5 音效（build/sfx/*.wav）
python3 build/mix_dub.py            # 多轨混音 + 合成配音版成片
python3 build/make_mlt_dub.py       # 生成配音版 Kdenlive 工程
```

产出：

| 路径 | 内容 |
|---|---|
| `05-音频/配音/试音/{林一,一林,陈晓,旁白}.wav` | 四条音色试听（先听这个确认音色） |
| `05-音频/配音/V01…V26_角色.wav` | 逐句对白（V11 镜面声为 3 段叠声） |
| `05-音频/配音/manifest.json` | 每句的镜号、起止、时长、是否超出配额 |
| `build/voice.wav` | 按时间轴合成的整条人声轨（约 136s，24kHz） |

> 部分句（V02/V08/V14/V21 等）生成时长超过字幕窗口，属正常语速与字幕排版差异；
> `build_stem` / `build_track` 会按窗口自动 `atempo` 轻缩（上限 1.5×）。
