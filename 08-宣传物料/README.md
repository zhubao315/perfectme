> 轻薄半赛璐淡彩动漫风格……一名 15 岁中国男高中生独自站在由无数发光镜面组成的教室空间中央，镜中映出多个更明亮、正在标准微笑的自己（青蓝柔光描边、领口发光满环徽章），冷灰蓝阴影与一抹暖橙光线对撞，地面有破碎镜面化为的柔和光点。竖版/横版构图，留白用于标题，无文字，无水印。

## 二、使用建议

- **社交平台**：主海报（竖版/方形九宫格）+ 预告片 + 文案包对应平台段落。
- **展板/易拉宝**：使用 `展架-易拉宝.png`，或按现场尺寸等比缩放。
- **投稿/展陈**：`作品信息卡.png` + `投稿清单与合规核对.md`。
- **公众号**：`公众号头图-900x383.png` + 文案包 §8.2。

## 三、原创性

角色、场景、台词、分镜、提示词均为原创；图像（Qwen-Image-2.1）、配乐（ACE-Step）、配音（Qwen3-TTS）、音效（程序化合成）均由本机开源模型/脚本生成，不含任何第三方下载素材。
