## 一、本片已实现的「反 PPT」处理（当前 mp4 即为该版本）

| 层级 | 手法 | 说明 |
|---|---|---|
| 镜头层 | 慢推 / 慢拉 / 慢移 + `sin` 呼吸 | 每镜用正弦微幅（缩放 ±0.005、位移 ±5~7px）持续「呼吸」，取代线性 Ken Burns，空间在动而非图片平移 |
| 缓动层 | **表情/动作缓动镜（`clip2`）** | 关键镜（S03/S06/S10/S15/S22/S26/S27/S31）用 AI t2i 变体（更消沉/假笑/抬头看虚影/更痛苦/释然微笑/伸手/笑更盛/放下手机）在同一镜内做一次 0.5s 交叉溶解，从姿势 A 缓动到 B，非硬切、**不加时长** |
| 剪辑层 | **交叉溶解 0.5s** | 34 段之间一律 0.5s 交叉淡化，无硬切（这是「不像 PPT」的关键） |
| 光效层 | 漫射柔光缓慢漂移 | 偏冷柔白径向光，`sin` 缓慢平移（周期 ~90s），营造「午后 / 空气 / 记忆感」 |
| 纸纹层 | **受亮度约束的纸纹颗粒** | 细颗粒以 `softlight` 经**亮度蒙版**混入，只在中亮部显出纸感，暗部干净（不冒噪点）；近似「纸纹缓慢变化」 |
| 字幕层 | 淡入 + 上浮 + 关键词渐暖 | 每句 `\fad(450,450)` + `\move` 上浮 14px；关键词（完美/优秀/喜欢/讨厌自己…）由白**渐变为暖金** |

> 纸纹为「合成颗粒」而非真正拆层；真正的分层纸纹流动、人物眨眼呼吸见第二节的分层重制建议。

## 二、分层建议（Krita 烘焙 + OpenToonz / AE 合成）

静态插图请先拆成**可动的零件**，各层独立导出 PNG（透明底），再做差速运动：

1. **人物层（中景）** — 眨眼、呼吸起伏、发丝/领结微动、手指小动作、视线偏移
2. **前景层** — 课桌、书本、窗框、树叶、发丝、校服飘带：轻微摆动/浮动
3. **背景层** — 教室、走廊、天空、树影：最慢位移 + 光晕变化
4. **纸纹层** — 半透明纸纹，极慢循环移动（1–3px，透明度 5%–15%）
5. **光效层** — 窗边柔光、空气光斑：只做透明度变化与缓慢扩散
6. **字幕层** — 淡入 / 上浮 / 关键词变色 / 下划线

视差量级建议：前景 > 中景 > 背景；纸纹与光效独立漂移，速度各不相同。

## 四、单镜节奏模板（每段 2–6s）

- **0–1s**：纸纹 + 柔光起，字幕淡入；
- **1–3s**：镜头缓慢推进，人物眨眼/发丝微动，背景树影移动；
- **3s 尾**：画面停在人物表情或窗边光效，字幕轻轻淡出。
- **缓动镜**：时长的前 1/2 为姿势 A，后半为变体 B，中点为 0.5s 交叉溶解（表情/动作的「呼吸式」变化）。

## 五、避免清单（会破坏淡彩校园感）

快速闪白 · 剧烈缩放 · 3D 旋转 · 强转场特效 · 画面震动 · 夸张卡通变形 · 大字突然砸下。
动画优先选择「慢、柔、细」的方式。
