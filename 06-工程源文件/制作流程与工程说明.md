## 三、一键复现（命令行）

```bash
cd /oc/mov
python3 build/build.py      # 生成 07-成片/满分的我.mp4
python3 build/make_mlt.py   # 生成 06-工程源文件/满分的我-工程.mlt
```

`build.py` 流程：图片 → `zoompan` 呼吸式慢推/慢移（正弦微幅，非线性推拉）→ 逐段编码
→ **逐段手写交叉淡化 0.5s（避免整图硬切；`clip2()` 在缓动镜内再做一次 0.5s 表情/动作过渡）**
→ 叠加缓慢漂移的柔光与受亮度约束的纸纹颗粒
→ libass 烧入 ASS 呼吸字幕（淡入上浮 + 关键词渐暖）→ 混入 ACE-Step 原创配乐 → H.264/AAC 输出（faststart）。
镜头/台词/音效由 `build/scene.py` 统一声明，`build.py` 生成 `build/timeline.json` 供配音脚本对齐；
片头字幕卡由 `make_title_card()` 以 `开场背景.png` + 柔暗渐变 + 主题化片名（暖金「我」字 / 点赞爱心 / 青蓝辉光）合成；
片尾电影式滚动字幕由 `credits_clip()` 生成（心理学理念 / 制作工具与组件 / 祝福 / 版权），
末帧由 `make_end_card()` + `still_card_clip()` 定格在居中的"感谢观看"。

## 四、如何在 Kdenlive 中打开与继续编辑

1. **打开工程**：Kdenlive → 打开项目 → 选择 `06-工程源文件/满分的我-工程.mlt`。
2. **轨道结构**：
   - `V1`：34 个镜头片段（按分镜顺序排列，已含运动效果，末两段为片尾滚动字幕与"感谢观看"定格）。
   - `A1`：环境音乐 `music.wav`。
   - 视频轨已挂「字幕」效果（`avfilter.subtitles` → `subs.ass`）。
3. **继续编辑**：
   - 拖入新片段 / 调整时长即可改变节奏；
   - 字幕在 `项目素材箱 → 效果 → 字幕` 或编辑 `subs.ass` 后重载；
   - 需要真实转场时，在片段接缝处拖入「溶解 / 白闪」。
4. **导出**：Kdenlive → 渲染 → 预设 `MP4 (H.264 / AAC)`，1080p 25fps。
   （若要缩小体积可再调 CRF；当前成片约 60 MB，远小于 200 MB 上限。）

> 也可用 Shotcut/`melt` 直接打开该 `.mlt`；已验证 `melt` 可完整渲染。

## 五、如何在 OpenToonz 中制作/继续动画

本工程采用"**关键帧图 + 缓动运动**"的微动漫（motion comic）方案；
若需逐帧补间，可在 OpenToonz 中这样组织：

1. **新建场景**：`File → New Scene`，命名 `满分的我`。
2. **导入素材**：把 `04-分镜图/镜头/*.png` 作为 Level 导入
   （`Scan & Cleanup` 或直接拖入 `Level Strip`）。
3. **分层**：建议每角色/背景一层：
   - `BG`（场景层）、`LinYi`（林一）、`YiLin`（一林）、`ChenXiao`（陈晓）、`FX`（光效/镜面）。
4. **时间轴**：按 `01-脚本/满分的我-分镜表.md` 的时长放置关键帧，
   用 `Animation → Keyframe` 给位置/缩放做缓动（Ease In/Out），
   即可把静止原画变成有呼吸感的动画。
5. **导出**：`Render` 输出 PNG 序列（带 Alpha）或直接输出 MP4，再回 Kdenlive 精剪。
6. **镜面/光效**：第三幕"三面镜子"建议在 OpenToonz 用 `FX → Warp / Blur / Glow` 叠层实现，
   碎片光点用粒子或手绘逐帧。

## 六、如何在 Krita 中绘修

- 打开 `04-分镜图/镜头/*.png`，用图层补绘手感线、修正五官比例。
- 需要透明角色层时，抠出人物后导出 PNG（保留 Alpha），供 OpenToonz 使用。
- 建议笔刷：`Ink` 系勾线（改用深蓝灰 / 暖褐彩色线稿）+ `Digital Watercolor` 上色，
  叠加淡淡的纸张颗粒纹理，保持「轻薄半赛璐 / 淡彩赛璐」的水彩绘本观感。
