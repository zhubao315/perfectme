制作流程PIPELINE

  1. 策划：剧本 → 分镜 → 逐镜动画分镜（DOC-A1/A2/A3）
  2. 视觉：角色设定 + 6 轮提示词 → Qwen-Image-2.1 → 04-分镜图/
  3. 动画：分镜图 → 呼吸式镜头运动（ffmpeg）/ OpenToonz → build/clips/
  4. 音频：ACE-Step 配乐 + Qwen3-TTS 配音 + 自研音效 → 05-音频/{BGM,配音,多轨}
  5. 合成：build/build.py → 字幕版成片；build/mix_dub.py → 配音版成片
  6. 工程：make_mlt.py / make_mlt_dub.py → 06-工程源文件/*.mlt
  7. 宣传：主视觉 + 文案 + 预告片 → 08-宣传物料/
